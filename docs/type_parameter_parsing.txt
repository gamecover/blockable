표기 기준
- "사용 안 함": 해당 필드는 이 type의 실행 계산에 사용하지 않는다.
- "무시": JSON에 값이 있어도 런타임이 정해진 값으로 강제하거나 실행에 반영하지 않는다.
- duration: 0은 즉시 또는 1회, 1+는 지정 턴, -1은 전투 종료까지, -2는 자동 만료되지 않는 영구 레이어다.

범위 target 공통 기준
- self: 자신
- Lx: 기준 대상과 왼쪽 x개
- Rx: 기준 대상과 오른쪽 x개
- Bx: 기준 대상과 양쪽 x개
- all: 살아 있는 전체 대상
- 피해, 상태 피해, 디버프, 군중 제어, 버프 모두 같은 범위 해석기를 사용한다.
