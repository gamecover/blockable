BLOCKABLE 업데이트 내역

v0.5.0
- 현재 게임 구성, 프로젝트 구조와 Block/Monster Designer 데이터 흐름을 README에 반영했습니다.
- Git 업로드 대상을 필수 문서, 설정, 소스와 런타임 에셋으로 제한하는 허용 목록 방식의 .gitignore를 적용했습니다.
- Block Designer v1.2.2의 스키마 1.1.0 데이터(블록 28개, 조합식 47개, 효과 정의 8개)를 다시 반영했습니다.
- 블록 효과의 단계별 적용 순서, 조건형 슬롯과 공통 색상 조건 판정을 보완했습니다.
- draw_block 효과를 다음 손패의 추가 드로우에 연결하고, 블록 상태 효과를 몬스터 상태에 연결했습니다.
- JSON 기반 블록 디자인 데이터와 전투 효과·조합 계산을 연결했습니다.
- JSON 기반 몬스터 디자인 데이터와 출현 조건, 체력, 행동 패턴 및 어빌리티 효과를 연결했습니다.
- 몬스터의 피해, 방어도, 회복과 상태 효과를 기존 전투 변수에 연동했습니다.
- 출혈, 화상, 약화, 상처와 기절의 기본 처리 및 전투 HUD 표시를 추가했습니다.
- 몬스터의 다음 행동과 실제 사용 어빌리티 이름 표시를 추가했습니다.
- 몬스터별 전투 이미지를 적용하고 이미지가 전투 조작 버튼을 가리지 않도록 배치를 조정했습니다.
- 끓어오르는 용광로 기사 이미지를 seething_furnace_knight.png로 정리했습니다.
- 임시 Asset 및 Assets 폴더가 Git에 포함되지 않도록 설정했습니다.
- 임시 전체 지도 이미지를 런타임 에셋으로 옮기고 일반 던전 2개와 중앙 최종 던전 선택 화면을 추가했습니다.
- 일반 던전 2개 완료 시 중앙 최종 던전이 해금되도록 진행 상태와 저장 상태를 연결했습니다.
- 난이도 1 던전을 2층으로 구성하고 1층 계단, 2층 보스, 완료 방 경로 자동 이동을 적용했습니다.
- 개발자 모드에서는 잠긴 던전과 모든 던전 방을 직접 선택할 수 있도록 유지했습니다.
- 일반전 1~4번 슬롯과 보스전 5번 보스 슬롯을 추가하고 몬스터 선택, 고정 슬롯, 개별 행동 의도를 표시했습니다.
- 일반전은 모든 적 처치 후, 보스전은 5번 보스 처치 즉시 승리하도록 조건을 분리했습니다.
- 전체 대상 피해를 JSON의 all_enemies 대상 값에 따라 살아 있는 모든 몬스터 슬롯에 적용했습니다.

v0.5.1
- v0.5.1 지도 명세에 맞춰 기존 단계·레인 기반 지도를 방·양방향 통로 기반의 2차원 탐험 지도로 전면 교체했습니다.
- 난이도 1을 2층, 층당 5~7개 방, 주 경로 3~4개 통로, 막다른 브랜치 1개로 고정했습니다.
- 모든 층에 재합류하지 않는 dead-end 가지를 보장하고 일반 가지와 위험 가지를 구분했습니다.
- 인접 미완료 방 탐험과 완료된 방·통로를 이용한 왕복 및 자동 이동을 적용했습니다.
- 던전 지도와 전투 중 읽기 전용 지도를 방 타일·통로 중심의 Darkest Dungeon 방식으로 변경했습니다.

v0.5.2
- Block Designer 베타 스키마 1.2.0을 연결하고 target, range, distance 및 amount 표준 파라미터를 적용했습니다.
- 블록 범위 피해를 일반·보스 전투의 고정 슬롯 판정과 연결하고 새 색상 시너지 데이터를 반영했습니다.
- 베타 효과 정의의 미연결 상태 ID와 조건부 필수 파라미터를 런타임 검증에서 진단하도록 보완했습니다.
- 전투 도구 주머니의 고유 블록은 임시로 강철 텍스처를 사용하되 각 칸에 X 표시가 나타나도록 구분했습니다.
- 개발자 지도 도구에 현재 체력과 최대 체력을 함께 25 올리는 버튼을 추가했습니다.
- 갱신된 Block Designer 연동 지침에 맞춰 베타 JSON을 다시 파싱하고 수치 범위, 조건 ID와 색상 참조 검증을 보강했습니다.
- 저주, 전설, 고유 블록 전용 텍스처를 React 미리보기와 Phaser 전투 블록에 연결하고 고유 블록의 임시 X 표시를 제거했습니다.
- 블록 선택 화면에서 고유·전설 텍스처가 잘려 보이지 않도록 대체 배경 스타일의 적용 조건을 수정했습니다.
- 개발자 전투에서 Z 키로 가장 최근에 거푸집에 배치한 일반 블록을 강철, 물, 자연, 불 순서로 변경할 수 있게 했습니다.
- v0.5.2 전투 공식에 맞춰 단일 블록 기본 공격 B를 H회 개별 처리하고 조합·시너지 공격 A를 별도 타겟팅하는 전투 계산기를 적용했습니다.
- 분노 P, 약화 D, 상처 W, 방어도 소모와 대상 사망 시 남은 연타의 자동 재지정 금지를 전투 처리에 연결했습니다.
- 출혈·화상을 몬스터 행동 이후 턴 종료 단계로 이동하고 기절 행동 취소, 추가 턴의 몬스터 행동 생략 및 상태이상 순서를 반영했습니다.
- 기존 effect_id/parameters JSON과 신규 type/value/target 공통 효과 형식을 함께 읽는 호환 어댑터를 추가했습니다.
- 새 게임에서 전체 지도에 처음 진입하기 전에 전체 고유 블록 중 무작위 3개를 제안하고, 세이브당 하나만 선택하도록 변경했습니다.
- 던전 입장과 계단 층 이동 시 해당 층 시작 방으로 즉시 이동하며 시작 방을 완료 처리하도록 변경했습니다.
- 던전 내부 공통 메뉴에 이동 기능이 없는 읽기 전용 전체 지도 확인 화면을 추가했습니다.
- 전체 지도 던전 버튼의 hover 위치 이동을 제거하고 시각적 강조만 적용했습니다.
- 일반 던전 완료 여부와 관계없이 중앙 최종 던전에 입장할 수 있도록 변경했습니다.
- 일반 전투는 몬스터가 최대 2마리, 보스 전투는 보스 1마리만 출현하도록 변경했습니다.

v0.6.0
- 3×3 이하 조합을 기본 공개하고 실제 발동한 대형 조합을 세이브별로 기록하는 청사진 도감을 추가했습니다.
- 발견한 청사진 목록을 일반·개발자 게임의 각 세이브 데이터에 유지하고, 이미 발견한 조합은 중복 등록하지 않도록 했습니다.
- 공통 우측 상단 메뉴에 청사진 버튼을 추가하고, 전투 거푸집 왼쪽에 현재 손패로 가능한 퀵 조합 세로 목록을 임시 배치했습니다.
- 공개된 퀵 조합을 거푸집으로 드래그하면 실제 손패 블록과 남은 배치 횟수, 활성 칸 및 충돌을 검사해 조합식대로 한 번에 배치하도록 연결했습니다.
- 퀵 조합도 턴당 최대 3개 배치 제한을 지키며, 조건을 충족하지 못하면 블록을 생성하거나 일부만 배치하지 않도록 했습니다.
- 퀵 조합 드래그 중에는 카드 대신 조합 블록 형태를 커서 중심에 반투명하게 표시하도록 개선했습니다.
- 미공개 조합을 전투에서 처음 발동하면 조합 이름과 청사진 등록 안내 팝업을 표시하도록 추가했습니다.
- 전투 퀵 조합 목록에서는 현재 손패와 남은 배치 횟수로 만들 수 없는 조합을 숨기도록 변경했습니다.

v0.6.1
- 몬스터 슬롯을 1~4번 전면 가로 대형과 5번 후방 중앙 보스 위치로 구성하고, 선택한 슬롯의 일러스트를 뒤쪽 대형 영역에도 표시하도록 개선했습니다.
- 사각형 몬스터 카드 프레임을 제거하고 투명 몬스터 일러스트 자체를 선택 가능한 전투 슬롯으로 사용하도록 변경했습니다.
- 각 몬스터의 체력 바와 다음 행동, 버프·디버프 상태를 일러스트 바로 아래에 배치했습니다.
- 거푸집 예상 수치의 `기본·독립` 용어를 `공격력·효과`로 변경하고 값이 0인 공격력, 효과, 방어, 회복 항목은 숨기도록 정리했습니다.
- 거푸집 예상 효과 표시 영역의 배경·테두리·문자 대비와 레이어를 높여 전투 화면에서 선명하게 표시하도록 개선했습니다.
- 선택한 일반 몬스터는 중앙 전면으로 이동·확대하고 나머지 일반 몬스터는 번호 순서를 유지한 채 겹치지 않는 최소 간격의 후방 대형으로 재정렬하도록 적용했습니다.
- 별도로 중복 표시되던 반투명 대형 몬스터 이미지는 숨기고 실제 전투 대형의 일러스트만 표시하도록 정리했습니다.
- 5번 보스의 선택·행동 위치와 후방 대기 위치를 위로 올려 하단 전투 UI 및 개발자 로그와 겹치지 않도록 조정했습니다.
- 보스 전신 일러스트의 레이아웃 높이를 별도로 확보해 체력·행동·상태 정보가 이미지 몸통이 아닌 완전한 이미지 아래에 표시되도록 수정했습니다.
- 5번 보스가 후방에 있을 때는 체력 정보를 이미지 아래에 유지하고, 타겟팅되어 전면 확대될 때는 이미지 하단 기준선으로 정보 영역이 올라오도록 상태별 위치 전환을 추가했습니다.
- 임시로 강력 노드의 일반 몬스터 출현 수를 2~3마리로 변경했습니다.
- 블록 배치 중 선택한 중심 대상과 실제 단일·범위·전체 공격에 포함되는 몬스터 슬롯을 구분해 강조하도록 추가했습니다.
- 몬스터 행동을 슬롯 순서대로 분리하여 현재 행동 중인 슬롯 번호와 어빌리티를 표시한 뒤 실제 효과를 적용하도록 연출과 계산 시점을 맞췄습니다.
- 사망한 몬스터는 비활성화하고, 기절한 몬스터는 해당 슬롯에서 행동 취소를 표시하도록 적용했습니다.
- 몬스터가 기본 공격 또는 어빌리티를 사용할 때 행동 슬롯을 밝게 강조하고 플레이어 방향으로 짧게 전진한 뒤 복귀하는 공격 애니메이션을 추가했습니다.
- 각 층의 시작 방과 계단·보스 방 사이 최단 경로 중앙에 휴식 방이 반드시 생성되도록 변경했습니다.
- 휴식 방에서 일반 블록의 속성 주입, 체력 20 회복, 일반 블록 모양 변환 중 하나만 선택해 적용할 수 있도록 추가했습니다.

v0.6.2
- 전투 승리 보상 카드는 블록 이름 대신 모양 이미지, 속성, 실제 효과만 표시하도록 단순화했습니다.
- 이벤트와 휴식의 블록 선택 목록은 화면상 문자를 제거하고 블록 이미지만 표시하되 접근 가능한 이름은 유지했습니다.
- 전투 하단의 남은 블록과 버린 블록 수량 버튼을 누르면 각 더미의 실제 블록 이미지를 확인할 수 있는 창을 추가했습니다.
- 타겟팅되거나 행동 중인 전면 몬스터의 표시 크기를 130%로 확대했습니다.
- 몬스터 화면 하단에 5번 보스 상단, 1~4번 일반 몬스터 하단 구조의 고정 정보 프레임을 추가하고 일러스트와 동일한 타겟팅·범위·행동 강조 상태를 연결했습니다.
- 휴식의 속성 주입 단계에서 선택한 블록과 자연·물·불·강철 변환 결과를 문자 대신 실제 블록 이미지로 비교하도록 변경했습니다.
- 게임 시작 고유 블록 선택 카드도 이름과 설명 대신 블록 이미지, 속성, 실제 효과를 표시하도록 통일하고 효과가 없으면 해당 영역을 비워 두도록 변경했습니다.
- 휴식의 모양 변환 단계에서도 선택한 원본 블록과 I·L·O 변환 결과를 문자 대신 실제 블록 이미지로 표시하도록 변경했습니다.
- 몬스터 고정 슬롯 보조 프레임을 전투 로그와 겹치지 않는 우측 상단 전용 영역으로 옮기고 몬스터 표시 영역을 그 아래로 분리했습니다.
- 몬스터 보조 프레임의 빈 슬롯 표시를 숨기되 1~4번 고정 슬롯 간격은 유지하도록 변경했습니다.
- 최대 5마리 편성 공간을 유지하면서 몬스터 진영을 우측으로 이동하고, 비타겟 몬스터는 15% 축소하고 전면 타겟 몬스터는 15% 확대했습니다.
- 비타겟 일반 몬스터의 크기는 유지하면서 후방 수평 기준선을 위로 올려 전면 타겟 뒤에서도 2·3·4번 일러스트가 모두 식별되도록 배치를 조정했습니다.

- 몬스터별 행동 아이콘을 후방·전면·보스 이미지 비율에 맞춰 실제 머리 위 기준선까지 내리고 일러스트와 겹치지 않도록 위치를 분리했습니다.
